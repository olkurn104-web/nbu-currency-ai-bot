
Десктопний додаток на Python для миттєвої конвертації будь-якої іноземної валюти в гривні за актуальним курсом НБУ з інтегрованим AI-помічником на базі OpenRouter.

![Скріншот програми](screenshot.png)

1. Встановіть необхідну бібліотеку:
   `pip install -r requirements.txt`
2. Відкрийте файл `check2.py` та вставте свій API-ключ OpenRouter у змінну `API_KEY`.
3. Запустіть програму:
   `python check2.py`
   
- Спроєктував(ла) ідею швидкого вводу суми разом із кодом будь-якої валюти в одному рядку (`100 USD`, `100EUR`) із заокругленням результату до цілих гривень.
- Реалізував(ла) отримання актуальних курсів усіх валют із відкритого API Національного банку України (НБУ).
- Протестував(ла) роботу конвертера та налаштував(ла) підключення до OpenRouter API.

- ШІ допомагав структурувати код за принципами ООП (розділення логіки на класи `NBUCurrencyService`, `OpenRouterBot` та `FinanceApp`).
- Допоміг реалізувати регулярні вирази для розпізнавання вводу без пробілів, обробку помилок мережі (офлайн-режим) та графічний інтерфейс на `tkinter`.
